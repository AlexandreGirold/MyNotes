# Agent mistakes and corrections

Concrete observations from this project. No credentials, private transcripts or complete logs are stored here.

| Observation | Cause / confidence | Correction and evidence | Reusable rule |
|---|---|---|---|
| Large delegated tasks sometimes returned empty/cancelled results or incomplete code. | Observed; early audio helpers also had incorrect download/queue/alignment logic. | Main agent reviewed and rewrote the helpers; raw-preservation, queue-order and real-model checks were added. | Send a compact context packet, one bounded deliverable and exact contracts. Never treat an empty result or a build alone as acceptance. |
| An early alignment implementation lost later matches after one unmatched word. | Confirmed greedy matching defect. | Sequence matching now preserves later anchors; unmatched/overlapping words remain unknown. `tests/test_diarization.py` checks both behaviors and raw text preservation. | Test a real mismatch in the middle, not only a perfect-match case. |
| Audio code initially used a custom WAV header writer when the standard library was sufficient. | Unnecessary code and incorrect header/finalization behavior. | Replaced with `wave`; protocol tests read the finished WAV and verify a job is announced after closure. | Prefer the standard library and verify the actual file/protocol, not a mirror of the writer. |
| A newly installed audio package lacked its native runtime; a separate decoder API changed. | Confirmed by real-model execution, not synthetic tests. | Added matching Sherpa core runtime; reused the already-decoded PCM array for tiny anchors. Real source/frozen model checks passed. | Run one real dependency-path check before claiming model integration works. |
| Desktop acceptance hung after the user's physical session switched to the login screen. | Backend startup succeeded; rendering on the inactive display stalled. | Source and packaged checks passed on isolated Xvfb/software rendering. Simulator keyring and runtime discovery were separated from the real app. | Isolate UI test displays and credentials; distinguish environment blockers from product failures and record exact coverage. |
| The microphone UI reported success using a returned level even when it differed from the requested level. | Confirmed missing verification; source changes and duplicate callbacks were possible. Browser AGC was not explicitly disabled; its contribution to the reported resets is not yet measured. | Source-pinned readback and GUI race guards added; full capture verification remains in progress. | Success must mean the requested operation was verified. Check competing gain controllers, all capture callers and the live path. |
| Delegation prompts omitted a reusable compact state/tool packet and agent profiles exposed unnecessary tools. | Confirmed configuration/workflow issue. | Qwen role permissions now default-deny; skill requires compact context, exact paths/commands and honest enforcement scope. | Supply verified context once. A prompt-only path restriction is not a sandbox; never claim otherwise. |
| Nested folders appeared beside their parent instead of below it. | Confirmed: `.view-notes li` applied library flex layout to the entire workspace tree. | Scoped that rule to the library list; separate file-tree CSS and packaged geometry checks verify parent/child layout. | Check inherited/global styling against a realistic nested fixture, not only a component's markup. |
| Internet tools existed but direct chat could not research the web; source links also opened no browser. | Confirmed capability gap in direct chat and unconditional Electron new-window denial. The user's specific old model response was not reproduced. | Added explicit Search the web evidence retrieval and HTTPS external-link handling, with real public-page/local-model packaged acceptance. Search-provider captcha/relevance problems remain reported honestly. | Verify the complete user action → actual source fetch → model input → clickable citation path. Tool registration alone is not acceptance. |
| Screenshot capture showed the previous tab despite updated DOM assertions. | Confirmed compositor lag in the offscreen smoke. | Wait for painting before capture, then inspect the rendered images. | DOM success and visual success are separate checks. |
